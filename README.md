# Employee Management

Gerencie o cadastro de funcionários para distribuição de brindes.

## 🛠️ Tecnologias
- Vue.js (Frontend)

## 🚀 Como rodar
1. Clone o repositório.
2. No ambiente local, execute: `npm run dev`
